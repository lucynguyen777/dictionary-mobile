## Runtime cache policy
- Policy: runtime caches and per-run logs generated by local crawling should be ignored from version control by default. Sample lists, canonical fixtures, and tests should be kept under `data/headword-lists/` or `tests/fixtures/` as appropriate.
- Paths to ignore (proposed): `data/wiktionary-cache/`, `data/wiktionary-bulk-runs/`.
