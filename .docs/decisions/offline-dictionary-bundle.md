# Decision: Offline Dictionary Bundle

## Status
Proposed

## Context
Offline dictionary support requires a legal data source, bundle format, update strategy, storage limits, and language coverage plan before implementation.

## Options
1. Open licensed offline datasets
2. Commercial licensed offline bundle
3. User-imported dictionary bundle
4. Online lookup only

## Decision
Chosen option.

## Consequences
Cost, security, implementation complexity, app size, update workflow, attribution, redistribution rights, indexing strategy, and offline performance.

## Tasks Unblocked
- Offline dictionary database
- Offline search indexing
- Offline language packs
- Licensed dictionary packaging
- Offline lookup quality improvements
