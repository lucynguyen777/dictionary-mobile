# Decision: Dictionary Source Licensing

## Status
Proposed

## Context
Production dictionary features require trustworthy lexical sources with licenses that allow app usage, redistribution where needed, and offline packaging where applicable.

## Options
1. Public API sources with allowed usage
2. Open lexical datasets
3. Commercial licensed dictionary data
4. User-provided personal dictionaries

## Decision
Chosen option.

## Consequences
Cost, security, implementation complexity, attribution requirements, redistribution limits, offline availability, update workflow, and language coverage.

## Tasks Unblocked
- Production multilingual dictionaries
- Offline dictionary bundle
- Etymology source integration
- Conjugation source integration
- Bilingual dictionary expansion
